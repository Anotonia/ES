## 组织原则

- **场景是主索引**：按“要完成什么交流任务”学习（点单、约人、看病、表达意见等）。
- **单词是节点，关系是记忆线索**：动词＋宾语、固定搭配、同义与对比、词族等。
- **区分认识与会用**：西语→中文的识别只是第一级；情境中不看提示用西语说出来才算掌握。
- **词根词缀辅助，不机械猜词**：形态拆分要符合真实构词法，注意词义与用法不能总由词缀推断。
- **思维导图是导航，不是考试成绩**：看完图后必须遮挡内容，完成主动提取、造句和对话。
- **周期不是绝对公式**：新学当天复习，随后参考第 1 / 3 / 7 / 14 / 30 天；错词提前回访，熟练词延长间隔。
- **CEFR 等级是教学目标的近似标签**，具体词条可能跨级出现；不要将单个词视为官方唯一等级。

## 每单元的流程

**输入场景 → 识别词块 → 找关系 → 关闭提示回忆 → 输出句子／角色扮演 → 记录错误 → 按间隔复习**

建议每单元约 15–25 个核心词／词块。初学时先掌握少量常用表达，之后扩展词族，而不是一天硬记几十条释义。

## 记录规范

CSV 最低字段：`id,level,unit,spanish,part_of_speech,meaning_zh,chunk,example_es,example_zh,relation,stage,last_review,next_review,error_count`。

学习表现的“未学习／识别／提示下输出／独立输出／迁移使用”是**操作性教学状态**，不是经科学验证的五级测量量表。

## 同步说明

GitHub 上的 Markdown 与 CSV 是项目的版本化知识库。每次新增单元或复习结果需要再次提交到仓库；**聊天记录不会自动、实时、双向同步**。请勿将私人医疗、身份或其他敏感信息放进词汇样例或学习记录。
