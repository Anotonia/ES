# 西班牙语词汇整理与学习｜A1–B2（西班牙生活版）

面向在西班牙生活、使用中文辅助学习西班牙语的人。项目以**准确、实用、可检索**为先，第一阶段先建立分级标准核心词汇库；核心词汇完善后，再另外加入**西班牙本地自然口语、语气词、常见俚语**，并明确场合与礼貌程度。

> **进度：第一批基础词汇已入库。** 当前共 264 条词汇/词块记录：A1 84、A2 60、B1 60、B2 60。所有词条配有中文核心义与西语例句，但还没有覆盖完整 A1–B2，也尚未逐条补全高频搭配和例句中译。

## 目前的整理顺序

1. **标准核心词汇**：按 A1、A2、B1、B2 和生活主题积累高频词/词块。
2. **补齐关键字段**：例句中译、固定搭配、词性/性别/变位提示、多义词辨析、去重与审校。
3. **构建词汇关系**：同一场景的动作、对象、反义对照、构词词族与思维导图。
4. **以后再扩展母语化自然表达**：在 [西班牙口语扩展计划](docs/西班牙本地口语扩展计划.md) 中独立归档，确保粗俗俚语不会混入正式用法。

目前**未开始正式收录俚语**。但词表已优先考虑西班牙生活情景（例如 `piso`, `abono de transporte`, `cita previa`, `empadronarse`），也保留跨地域的通用西语基础。
