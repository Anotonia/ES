# 西班牙语 A1–B2：8,000 词知识库、思维导图与长期记忆（西班牙生活版）

本仓库面向在西班牙生活的中文母语学习者。以日常生活实际交际为中心，先建立**词汇本体与真实搭配**，再将概念图、词根词缀、主动回忆和间隔复习连成系统。等标准词库达到可使用质量后，分层加入西班牙本地非正式口语与俚语。

## 长期学习方法

**场景化理解 → 词块与关系网络 → 词根词缀辅助 → 遮挡主动回忆 → 新场景输出 → 间隔复习。**

思维导图不是为了“看起来记住了”，而是为了组织线索，让学习者能够无提示重新构图和表达。后期再做西班牙本地真实口语与俚语分层：[口语扩展计划](docs/西班牙本地口语扩展计划.md)。

## 数据质量、许可证及隐私

- **候选池不是成品词典。** 原始词频可能含频率偏差、同形异义、用词不合阶段、地区差异，且大量候选没有中文解释。正式可学词表只按 **`data/vocabulary_master.csv`** 中已经编写内容计算。
- **来源署名**：`data/candidates/` 派生自 [doozan/spanish_data/frequency.csv](https://github.com/doozan/spanish_data/blob/master/frequency.csv)，原始词频源为 FrequencyWords，上游对应 **CC BY-SA 3.0**。过滤、去重、分桶和链接等改动详见[候选库及版权说明](docs/8000词候选库-分级与版权说明.md)。该数据目录的衍生频率词表继续按 CC BY-SA 3.0 提供。
- **仓库公开**：不得上传真实个人姓名和联系方式、身份号码、住址或其他敏感学习记录。
- **版本同步**：每次本对话写入 GitHub 是一次显式提交；没有设置聊天与 GitHub 的自动双向实时同步。
