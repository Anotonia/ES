## 一条记录代表什么

**记录单位**是“词汇项（vocabulary entry）”，可以是一个单词、性别变体、固定短语或高频表达，不等同于 264 个互不重合的单字形式。

### 数据结构（现行 14 列）

| 字段 | 作用 |
|---|---|
| `id` | 稳定标识；新条目 A1-001 等；示范单元 A1-CAFE-001 等 |
| `level` | A1、A2、B1、B2 教学分层（非官方逐词认证） |
| `unit` | 场景单元或主题 |
| `spanish` | 西班牙语基本词条／词块 |
| `part_of_speech` | 词性（含短语信息） |
| `meaning_zh` | 中文核心义，不代表全部可能词义 |
| `chunk` | 高频搭配（未补录时为空） |
| `example_es` | 西班牙语用法例句 |
| `example_zh` | 例句中文理解（未补录时为空） |
| `relation` | 场景/语义关系标签 |
| `stage` | 学习状态，初始均为“未学习” |
| `last_review` / `next_review` | 真实复习数据（初始为空） |
| `error_count` | 累计错误次数（初始为 0） |

## 编写进度与后续顺序

**阶段一：完善核心词汇（现在）**

1. 各等级按高频程度和生活任务扩展主题覆盖。
2. 逐条补充真实常见搭配、例句中文释义、容易误用的语法点。
3. 将同形多义与高频变位整理成专门的用法页，建立双向链接。
4. 对新条目开展去重、性数与变位核对；保证统计口径一致。

**阶段二：自然口语与母语场景（基础词表稳定后）**

- 另建 `spoken-es/`，收录西班牙实际交际中的自然说法、省略、语气、地区变体和常用俚语。
- 每条都与基础词项关联；标注情境、亲疏关系、地域、礼貌程度、是否粗俗，不把俚语无差别替换为“标准答案”。
- 详见 [口语扩展计划](./西班牙本地口语扩展计划.md)。

**阶段三：记忆与跟踪**

建立概念图、单词家族和可复习卡组。用户真实练习后再写入掌握状态和错误记录，绝不预设已掌握。
