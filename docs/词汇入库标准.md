# 西班牙语词汇入库与审核标准（ES）

## 词表目标

本库面向生活在西班牙、以中文为主要解释语言的西班牙语学习者。优先覆盖马德里及西班牙日常使用情景：住房、工作、交通、就医、手续、买菜、服务沟通，同时保留标准西语的跨地区通用表达。

**先建立 A1–B2 的可检索基础词表；口语、非正式表达和俚语另行补充**，避免学习者误把粗鲁/仅限熟人场景的用法当成正式场合的默认选择。

## 入库质量门槛

1. **词条形式**：动词使用不定式，名词尽量提供定冠词和性别线索，必要时注明复数或阴阳性变体。
2. **义项**：只填该等级最有教学价值的“核心义”，不把多义词误写为唯一义。
3. **语境**：每条至少有一条自然、可独立理解的西语例句。
4. **搭配**：下一轮为每个词扩充至少一个常见高频搭配或句型；新批次先保证例句正确。
5. **地域与语域**：泛西语表达可作为主词条；西班牙特有用法在注释中指出。之后口语层使用 `ES`、`Madrid`、`regional` 等地域标签，以及 `neutral`、`informal`、`slang`、`vulgar` 等语域标签。
6. **CEFR**：A1–B2 是教学选词与表达复杂度定位，不是“这个词只属于某个级别”的官方唯一判定。每种词的实际使用场景会跨级。
7. **ID 与去重**：以稳定 ID 维护记录。首次基础词库按各级编号，咖啡馆示范单元沿用 `A1-CAFE-` 前缀。新词按词条与义项检查是否真的重复。
8. **隐私**：本仓库公开。所有例句仅用虚构信息，不上传真实证件、住址、电话号码、姓名或其他个人资料。
9. **学习状态**：只有实际练习才填写掌握情况；目前 `stage=未学习`，复习时间留空。

## 审校重点

- 西语拼写（á/é/í/ó/ú/ñ/ü）、标点及大小写。
- 形态与词性（例如 `el agua` 虽使用冠词 el，名词依旧为阴性）。
- 地道的西班牙句法和固定介词（`confiar en`, `darse cuenta de`）。
- 不滥用词根词缀类比（构词同族不能保证意思可逐字推导）。
- 非正式/粗俗词汇必须在第二阶段以使用条件解释，不混入第一阶段。
- 每次增加数据，同步更新等级表、总表和索引统计。
