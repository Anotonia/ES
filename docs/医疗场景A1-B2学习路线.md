# 西班牙看病与医疗沟通｜A1–B2 完整场景路线

> 面向在西班牙生活的中文学习者，重点练习 **预约、家庭医生、检查/化验、专科转诊、药房、儿科与紧急沟通**。教学示例中所有角色和病情均为虚构；这不是诊疗、用药或急救操作建议。

## 西班牙医疗常见词语的区别

- **centro de salud**：社区医疗中心，通常涉及家庭医生、儿科、护理等基层医疗服务；医院门诊不一定由这里直接预约。
- **médico/a de familia**：家庭医生。
- **cita previa / pedir cita**：提前预约；**anular una cita** 为取消；**cambiar una cita** 为改约。
- **consulta presencial / telefónica**：面对面问诊／电话问诊，不是所有就诊类型都可以相互替换。
- **derivación**：转诊；**primera consulta** 和 **revisión**（复诊）可能有不同的预约途径。
- **prueba / analítica / extracción de sangre**：检查／化验／抽血；具体是否要空腹必须按检查指引核实。
- **informe / resultados**：医学报告／结果；出现超出参考值并不自动等于某种诊断。
- **receta electrónica / dispensación / prospecto / pauta**：电子处方／发药／药品说明书／用药方案。
- **urgencias / triaje**：急诊／分诊；急诊并不严格按到达先后顺序安排诊治，而按医护人员对病情的评估进行分流。

## 真实就医时的沟通原则

1. **只说确定的事实**：症状位置、开始时间、是否反复、是否加重。无法确定时直接说 `No estoy seguro/a`。
2. **让医生知道语言障碍**：`Estoy aprendiendo español. ¿Puede hablar más despacio?` 必要时可以主动询问是否有语言协助渠道。
3. **药物名称、剂量、过敏不能猜**：可要求核对药盒、处方、说明书及病历；不要自行停药、加药或改变服用方案。
4. **不用示例替代判断**：身体不适如何处置由医护人员根据个人病情决定。对严重、危及生命的突发情况，西班牙可拨打 **112** 寻求紧急帮助。
5. **每次沟通至少确认三件事**：需要怎么做、何时进行、应该联系谁。

## 用网站学习

1. 打开 [医疗预约第一课](https://anotonia.github.io/ES/#/detail/hc-book-01) 或其他课程对应的入口。
2. 将朗读语速调整至 0.65–0.75×，先听对话，再逐句跟读。
3. 遮住中文译文，尝试独立复述。
4. 完成突发情境选择，阅读反馈，最后做闭卷表达与迁移挑战。
5. 录下自己练习的声音（如使用你自己设备的录音应用），重点检查能否自然提出追问。本网站当前不自动保存音频，也不提供自动口语评分。
