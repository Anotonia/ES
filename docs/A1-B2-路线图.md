## 一条词汇的完善标准

- 西语形式、词性/性别、核心中文义、真实例句。
- 至少一种常用搭配；必要时补充变位和介词规则。
- 多义词按“义项+情境”维护，避免只背中文单义。
- 对“西班牙本地常用”的词条注明地区和适用语域。
- 建立同主题、同词族、易混词的双向联系。
- 审核完再扩到口语层，而不是把俚语提前塞进 A1–B2 主词表。

## 一个单元的标准学习流程

**场景理解 → 核心词与词块 → 语义/构词关联 → 闭卷回忆 → 造句和角色扮演 → 错词记录 → 间隔复习**。

每个练习单元约 15–25 个重点词汇，进度依用户实际掌握情况调整；不依词表总数强行加速。
