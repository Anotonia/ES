# 词汇长期记忆系统｜按“能实际说出来”验收

## 推荐组合

**场景语义联结（组织） → 词块优先（编码） → 主动检索（巩固） → 适度构词分析（扩展） → 间隔复习（维持） → 新场景输出（迁移）**。

- **主线一：场景**。学习实际会遇到的任务，而不是只按字母表排列。例：`房租` → `alquiler, fianza, contrato`。
- **主线二：词块**。词条必须学会一个常见组合，例如 `pedir cita`、`presentar una reclamación`、`estar de acuerdo con`。
- **主线三：构词**。从基本词向少量真实派生词扩展，例如 `hacer → deshacer → rehacer`；词根推理后仍需核实实际含义。
- **主线四：网络**。用脑图将一个单元的动作、对象、场景和搭配连接，避免全表密集不可读。
- **主线五：主动检索**。遮住答案，中文意图→西语，直接说短句或完成对话。
- **主线六：间隔复习**。按照个人遗忘情况调整间距，回忆失败的项目立即改短间隔。

## 一次 20 分钟示例（A1）

| 时间 | 任务 | 验收 |
|---|---|---|
| 0–4 分钟 | 阅读一段 4 句对话并理解交际任务 | 能说清楚对话在干什么 |
| 4–7 分钟 | 学 8–12 个高频词块 | 知道基本意义与搭配 |
| 7–10 分钟 | 口头描述/重画语义图 | 找回至少 2–3 个关联分支 |
| 10–14 分钟 | 闭卷中→西主动提取 | 记录正确项和漏项 |
| 14–18 分钟 | 改变角色、对象或条件的情境输出 | 能自然完成沟通 |
| 18–20 分钟 | 纠错、登记错词与下次复习节点 | 不把识别当成掌握 |

## 推荐复习节点

初学当天完成首次闭卷提取，之后以第 1 / 3 / 7 / 14 / 30 天为**建议起点**；答错提前，容易答对则延后。时间间隔取决于个人遗忘率和表达任务，不能说这一组固定日期是经过验证的通用最优方案。

## 建议通过标准（本项目约定）

- **识别**：看西语能理解。
- **中文→西语提取**：看中文意思，不看词表能说出正确常用表达。
- **新句输出**：在新话题/场景下不照搬例句、仍能正确表达。
- **次周复习**：在更长间隔下仍能主动回忆。

每个单元保留高风险、易混与复杂结构复习，不能只统计“看着觉得认识”。

## 词根词缀 vs 记忆策略

词根/词缀与图谱帮助理解、组织和扩充，但对**长期保持的关键检查是主动回忆能否成功**。不要用观看脑图时的熟悉感代替真正的闭卷回忆。
