# ES 学习网站｜部署、维护与隐私

## 主要功能

本仓库 `docs/index.html` 是纯静态单页网站（HTML / CSS / JavaScript），**不需要后端服务器或账户登录**。

- **学校为主**：23 个学校场景，包含 4 条 A1→B2 连续学习路径（入学、学业、校园安全、食堂接送），以及原来的 7 个独立基础场景。
- **医疗重点**：已有医疗 6 个场景，加上预约、医生面诊、化验、药房及儿科急诊 5 条四级课程共 20 个新任务，医疗合计 **26 个**；银行及行政各 6 个。全站共 **61 个场景**。
- **额外深度病例**：独立于 61 个标准场景，新增 [6 条连续就医剧情](医疗深度连续病例与角色训练.md)、24 个四级章节、335 轮双语对话；支持遮中文、患者角色代入、理解测验、情境选择和开放式表达自评。
- **分级场景**：共有 48 个较完整的 A1→B2 任务，包含交流目标、至少 8 个词块、至少 7 轮双语对话、2 组自然/正式对照、**2 个可交互情境分支**、3 道闭卷题及 1 个独立迁移任务。详情见 [分级场景学习路径](分级场景学习路径.md)。
- **旧有独立场景**：仍保留较短的基础词汇、对话和自测。
- **口语层**：22 个表达，包括 `cole`、`profe`、`mates`、`apuntarse`、`qué guay`、`estar hecho polvo` 等，每条标注何时适用与什么时候不建议使用。
- **可视化**：分主题点击的词汇关系图、15 组构词词族；6 张已有 Mermaid 思维图保存在 `mindmaps/`。
- **复习**：无提示回忆、揭晓参考表达、自评掌握程度；使用浏览器本地记录安排后续复习。
- **朗读（已升级）**：由 `docs/assets/audio.js` 独立处理，默认 **0.70×**，可用滑块调节到 **0.55×–1.20×**，优先自动选择 **es-ES** 西班牙口音；系统提供多个西语声音时可手动选音色，并保存本机设置。
- **场景整段播放**：课程内提供「播放整段」「慢速跟读（最高 0.60×）」「暂停／继续」，顶部提供「重听」「停止」；当前句会高亮。语速／音色在下一句或重听时生效。
- **语音品质限制**：仍采用浏览器 Web Speech API 的合成语音，非真人录音或云端神经语音；能否显示较自然的西班牙声音取决于设备、浏览器和已安装的语音包。当前不需要 API key、不向第三方语音服务上传对话内容。

所有例句和场景均为**原创教学示例**，并非对政府、银行、学校或医疗机构当前流程的保证，更不是医学诊断、用药建议或急救操作指示。西班牙遇到紧急情况可拨打 **112**。

## 部署至 GitHub Pages

工作流 `.github/workflows/deploy-site.yml` 使用官方 GitHub Pages Actions 发布 `docs/`。

1. GitHub 仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
2. 在仓库 **Actions** 查看 `Deploy Spanish Learning Website` 是否成功。
3. 仓库为 `Anotonia/ES` 时，通常页面入口是 `https://anotonia.github.io/ES/`；**仅在部署成功并且网页实际可访问后，才能视为上线**。
4. 修改 `docs/index.html`、`docs/assets/` 后提交 `main`，工作流将再次尝试部署；仓库环境保护/Pages 开关可能影响结果。

本地运行：
```sh
python3 -m http.server 8080 -d docs
# 打开 http://localhost:8080/
```

## 修改数据时的自检

网站教学数据以 JSON 维护：
- 新分级 `scenarios`：`id, domain, track, level, stage, title, subtitle, goal, brief, vocab, dialogue, expressions, challenges, mission`。
- `mission` 包含 `setup`、至少两个 `decisions`（问题、若干可选回答与原因反馈）及 `transfer` 迁移任务。路径 `tracks` 独立标注全套四级课程。
- `colloquial`：`es, zh, neutral, register, use, avoid, example, topic`。
- `families`：`base, derived, relation, zh, example, group`。

```sh
python3 scripts/validate_site.py
node --check docs/assets/app.js
node --check docs/assets/audio.js
node --check docs/assets/pathways.js
node --check docs/assets/medical-deep.js
node scripts/smoke_site.js
python3 scripts/validate_lexicon.py
```

自动发布前会运行内容校验、三个前端脚本的语法校验和页面模拟测试；失败则中止部署。

## 数据隐私与学习效果限制

- 闭卷题、交互任务与自建导图进度保存在设备浏览器的 `localStorage`，**不自动同步到 GitHub**、账户或其他设备；清理网站数据可能清除学习状态。
- B1/B2 的决策练习包含合理但非最优的选项，重点是理解语境；答对一组选择**不等于已掌握 B1/B2 的口语能力**。
- 网站不会请求银行账号、孩子信息或医疗数据；不要把真实个人信息写进公开仓库。
- 自评参考答案并不是唯一正确译法；同义表达可正确。单击“能独立说出”不等于语言水平官方认证。
- 复习间隔 1、3、7、14、30、60 天是可调整的默认教学方案。
- 真实入学、请假和考试规则需查所属学校通知，银行费用需查开户行条款，行政流程依所属市政/地区机构要求变化。
