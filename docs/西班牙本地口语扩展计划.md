# 第二阶段计划｜西班牙本地自然口语与俚语（尚未开始入库）

## 为什么单独维护口语层？

日常西班牙语中，口语表达常涉及省略、情绪强度、人际亲疏、地区差异和场合差异。**正式、自然、熟人口语、俚语、粗俗表达必须区别对待**。先学基础表达，再学习口语变体，才能按需要准确切换语域。

## 未来的结构

`spoken-es/`（待创建）下按场景建库，与 `data/vocabulary_master.csv` 的稳定 ID 对应：

- 朋友聊天与聚会
- 酒吧、咖啡馆、街头购物
- 公共交通、邻里与物业
- 工作同事间非正式沟通
- 医院、行政机关与店员互动时的自然礼貌用法
- 对话中的语气词、插入语、省略表达
- 社交媒体、年轻人口语与常见俚语（标记年龄/地域与语域）

## 每个口语条目必须标注

| 字段 | 说明 |
|---|---|
| standard_reference | 对应标准表达或现有词库 ID |
| colloquial_expression | 实际听到的口语形式 |
| meaning_zh | 真实交流含义，不能仅按字面解释 |
| region | España/Madrid/其他地区/未定 |
| register | informal/slang/vulgar 等 |
| relationship | 朋友/同事/陌生人/长辈等 |
| situation | 适用与不适用场景 |
| example_es | 符合自然语境的原创例句 |
| notes | 语气、风险、地域差异、误用提醒 |
