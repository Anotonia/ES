# 医院深度学习｜从短对话升级为连续四幕真实流程模拟

本专题针对“词汇和对话过短，无法应付真正就医”的问题建立独立的**纵向医疗案例库**。从 [网站专页：医疗深度课程](https://anotonia.github.io/ES/#/medical) 进入，源数据见 [medical-cases-a.json](assets/medical-cases-a.json) 与 [medical-cases-b.json](assets/medical-cases-b.json)。

## 为什么不再只追求“场景数量”

旧版医疗场景以每节 7–10 轮示范对话为主，学习者虽能认出“预约”“药房”等词，却不一定能做到：

1. 把之前已经发生的就诊信息带到下次问诊。
2. 回答医生连续追问，而不是复述单句。
3. 将**事实、担忧、猜测、不确定性**分开表达。
4. 听懂工作人员说“尚未确认”“依具体程序办理”，并继续追问。
5. 结束前复述自己理解的计划、记录下一步联系渠道。

因此深度课程按**一条经历 4 个章节**组织；每章至少 13 轮中西双语对话、6 组词块、理解判断、突发情境回应及一项开放式输出练习。

## 每章五层训练

### 第一层：情境连续性与档案

每条故事沿一条时间线推进。章节顶部有虚构背景、当下问题和“下一幕信息”，如：上一幕告诉医生“喉咙痛从星期六起”；下次门诊不能改口说“咳嗽也从星期六开始”，必须保留“咳嗽从星期日出现”的信息。

### 第二层：主动听力（本地 es-ES）

- 可整段连续朗读，一句结束后自动播下一句。
- 可慢速跟读，语速由网站顶部控制。
- 可遮住中文译文。
- 可进入**角色代入**：隐藏患者或家长的西语句子，只显示中文提示，听医护人员提问后用自己的西语表达，再退出模式核对。

系统使用浏览器语音合成，**不能保证真人语调，也没有自动口语评分**。

### 第三层：词块而不是单词堆积

每章至少 6 组高价值词块及其使用说明。例如：
- `llevar + tiempo + con` → `Llevo varios días con tos.`（咳嗽已持续好几天）
- `No puedo asegurar que…` → 明确你目前没有足够信息。
- `Para asegurarme de haberlo entendido…` → 礼貌复述确认。
- `Que exista una petición no significa que haya una cita asignada.` → 已有申请不等于预约完成。
- `Distinguir lo confirmado de lo pendiente.` → 将已确认与待核实的部分分开。

### 第四层：理解题 + 情境转折

不能只认出关键词。每章至少有：
1. 一道事实理解题。例如“患者咳嗽从哪天开始，而喉咙痛从哪天开始？”
2. 一道情境决策题。例如“护士说了检查名称但没说明目的，你该怎样追问？”

两个环节都显示“这个答案为什么合适或为什么遗漏了关键问题”，不会用“粗鲁/礼貌”作为唯一判断标准。题目暂为固定分支，**还不是会动态扮演医生的 AI 对话**。

### 第五层：开放式迁移输出

先不看参考，写出自己打算说的句子；然后查看一种参考表达及四个检查要点，再自评能否脱稿表达。

**重要**：自由输入的内容不会上传到 GitHub，也不进行 AI 自动批改。只有选择题正确且学习者选择“能独立表达”，该章才在当前浏览器标为完成。若需真正评分，应继续进行人工或模型逐句纠错。

## 如何安排练习

建议一条完整故事用四次练习，不必一口气学完。每次可按：

1. **第一次**：整段听 1 次 → 看双语 → 记录 6 个词块。
2. **第二次**：遮住中文听 → 角色代入 → 自己说出患者一方的回答。
3. **第三次**：做事实理解、情境变化和开放式表达，严格要求“信息准确”。
4. **第四次**：脱离原话替换人物、日期、条件、就诊地点，再完成一次完整对话。

A1–B2 是**教学练习难度标注**，不是欧洲委员会对每段对话的逐篇认证。实际掌握程度需通过陌生材料理解、现场交际和产出表现检验。

## 医疗与隐私边界

- 本项目涉及的症状、人物与医疗经历均为虚构，不对个体提供诊断、用药剂量、检查准备或急救操作的判断。
- 医疗系统预约与保险政策因自治区、医院、保单而不同。需要核实官方程序时，可参考：[马德里 Cita Sanitaria](https://www.comunidad.madrid/salud/cita-sanitaria)。
- **发生现实医疗急症时，应立即按当地紧急程序求助；西班牙可拨 112。**
- 请不要把真实病史、儿童身份、医疗卡号、处方或医疗文件上传到公开 GitHub 仓库。开放练习应使用虚构内容。
