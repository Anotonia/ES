## 实际操作

选当前等级的一个生活主题 → 读 8–12 个词及例句 → 找 2–3 条搭配与语义连接 → 隐藏图谱闭卷恢复 → 造新句/模拟真实对话 → 记录错词 → 下次按间隔复习。

图谱只在“看完后能主动重新说出来”的条件下帮助记忆；单纯观看复杂脑图没有可保证的长期记忆效果。

详细流程：[长期记忆协议](记忆系统-学习协议.md)。A1 例子：[咖啡馆点单](../levels/A1/01-咖啡馆点单.md) 与 [高频功能词](../levels/A1/02-高频功能词与表达.md)。

## 西班牙生活版本与俚语层

基础教学尽量以**西班牙常见使用习惯**作为例句背景，但把一般标准西语和亲密口语/俚语做成不同用法层。第二阶段才正式整理俚语与表达频率，并标注 Madrid/其他地区、陌生人/朋友、自然/不礼貌、语气强弱等。详见 [口语计划](西班牙本地口语扩展计划.md)。
