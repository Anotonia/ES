# 8,000 西语词元候选池｜等级规划、质量限制和来源许可证

## 摘要

用户设定的**累计词汇目标**：A1 1,000；A2 2,500；B1 5,500；B2 8,000。按新增量分桶：A1 1,000；A2 +1,500；B1 +3,000；B2 +2,500。

目前已经建立 **8,000 个不重复候选词元**。其中大部分是带词频的**待审列表**，不等同于带中文释义/例句的正式教学词表，更不等于已学会。**本项目当前真正编写有西语例句与中文核心义的主词表为 827 条记录**（A1 355、A2 156、B1 159、B2 157）。

## 数据抽取及默认过滤

1. 从 `frequency.csv` 提取 `count, spanish, pos, flags` 字段。原始行约 25,018 条。
2. 删除 `DUPLICATE`、`NOUSAGE` 等带标志记录；排除未知词性、专有名词及非西语常规字符形式。
3. 按西班牙语小写规范化后去重；可选池约 17,337 个词元。
4. 将主词库里能可靠匹配的**单词词元**先保留在现有教学级别。短语、带阴阳性替代形式的条目不一定能直接做一对一匹配。
5. 其余词元按上游频率递减，填满 A1/A2/B1/B2 四个**暂定**学习桶至 1,000/1,500/3,000/2,500。
6. `review_status=initial_curated_match` 表示候选词能映射到主词库且与临时等级一致；`curated_other_level` 表示能映射，但教学等级与频率候选桶不同；均不代表官方 CEFR 认证。
7. `review_status=pending_manual_review` 的行可能缺中文、例句；正式入库前还需审校。2026-10 批次后，8000 候选词中有 **552** 条可按词形关联到正式学习主库（并非 827 条全部在词频候选池中）；其余候选仍待整理。

## 新编写的学习词条

2026-10 完成 [414 条净增记录](../data/expansions/)；正式主库共 **827 条**，各记录均有核心中文释义和西语例句。本批新增条目额外提供常用搭配与中文例句译文，但仍需词义、难度与语体审校。数量按记录计，不能直接视为 827 个不重复词元。

## 如何从候选词变成正式词表

- 审校词元/词性、去掉非高频或不适合生活的词，必要时换入更重要的词；
- A1 优先时间、数字、社交礼貌、家庭、购物、住所、交通等；A2 日常行政、医疗、租房；B1/B2 再增加抽象与专业表达；
- 对每个词确定教学级别和核心义，写出**中文释义 + 原创西语例句 + 常见搭配**；
- 名词记性别，动词常见搭配/介词，变位形式归类到词元；
- 对一词多义建立独立义项及场景关系；
- 双语解释与例句核校之后，才加入 [vocabulary_master.csv](../data/vocabulary_master.csv)，并更新索引。

## 官方框架与数目关系

欧洲委员会 CEFR 提供以能力为核心的等级描述，并没有强制所有语言、所有考生每级使用某个固定词数。西语课程主题可对照 [Instituto Cervantes PCIC](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/indice.htm)。本项目上述词数为用户选定的自定义累计目标。

### 为什么不直接把候选池等同于完整词表？

因为一个没有释义、词性核实、例句和练习的列表只能用于**选词与审校**。将这种候选列表标为完整 A1–B2 已学词汇会误导学习进度与考试准备。
