# A1–B2 学习与长期记忆方法｜证据、操作和边界

## 结论：不应在“词根词缀”和“母语模式”之间二选一

将**场景任务／语义网络**作为组织主干，加入**高质量输入与词块、显性构词知识、主动提取、间隔复习、真实输出**。词根词缀是扩词工具；思维导图是可视化索引；是否能在无提示时表达，是核心验收标准。

### 证据强度（归纳）

1. **主动提取（retrieval practice）与分散练习（distributed practice）**：学习策略综述将两者评为高效用，适合长期记忆；相比之下，仅反复阅读与划线效益不稳定。
2. **二语的间隔练习**：2022 年综述 48 项实验，间隔练习对二语学习整体有效。最佳复习间距受学习目标与评估时点影响，不存在适用于所有人的固定神奇日程。
3. **语义图/概念图（concept mapping）**：2025 年二语元分析观察到整体积极效应，尤其对产出技能。研究样本以英语二语教学较多，不宜把效果直接等同于所有中文母语西语学习者的结果。
4. **西语构词知识（morphological awareness）**：2020 年西语二语研究主张对有价值的派生构词规律给予显性教学。通过词族识别与扩词，而非凭词缀无条件猜意思。

## 实施顺序：理解 → 编码 → 检索 → 迁移 → 复习

**步骤 1｜情境接触**：先理解一段 2–4 句自然西语对话（必要时配中文解释），知道谁对谁说、为何说。

**步骤 2｜构建连接**：每个核心表达至少连接两个线索：
- 任务线索：`点单 → pedir → un café`。
- 词块线索：`pedir + comida/bebida`、`la cuenta, por favor`。
- 形态线索（合适时）：`trabajar → trabajador/a`。
- 语义对照：`aquí ↔ para llevar`（是本场景中的选择对照，**并非词典反义词**）。

**步骤 3｜遮挡回忆**：不看表格完成三种提取：场景→西语；中文意图→西语；西语线索→造句。每次对照纠错。

**步骤 4｜输出迁移**：用新词完成 30–90 秒角色扮演，至少替换一种条件（品类、人数、支付方式、礼貌程度），检验是否只背熟了原句。

**步骤 5｜间隔复习**：当天短回顾，建议约在第 1、3、7、14、30 天进行“闭卷产出”；若错，缩短间隔并重练；若能在新情境中正确使用，再延长间隔。以上日期是教学操作默认值，不是从研究直接得出的唯一最佳日程。

## 分级侧重点

| 等级 | 主要组织方式 | 词根词缀所占角色 | 主要输出 |
|---|---|---|---|
| A1 | 生存场景、具体物品、常用句框 | 仅解释特别清晰的形式变化 | 点单、介绍、问路 |
| A2 | 场景拓展、常见搭配、多义词 | 高频前缀及词族识别 | 复述经历、安排计划 |
| B1 | 词族、近义词/反义词、语义迁移 | 常见名词化、形容词化规律 | 描述原因、表达建议 |
| B2 | 抽象概念、语域、论证结构 | 构词推断＋异常与限制 | 论证、辨析、正式表达 |

## 如何使用脑图

- **先看图**：认识场景分支和连接词（谁做什么、什么搭配什么）。
- **再隐去图**：从中心主题空白重画或口述所有分支；随后补齐遗漏词。
- **最后走出图**：改变对话角色和情境，不看图自然表达。
- 一张图尽量只处理一个主题（约 12–25 个词/词块），多用“关系标签”而不是堆长句。
- 本项目以 Mermaid `flowchart` 保存可编辑概念图，GitHub Markdown 可渲染。

## 词汇条目的记忆和验收

- **识别**：看见 `pedir`，知道它可表示“点（餐）/请求”。
- **提示下输出**：看到“我要一杯咖啡”，用 `Quiero un café.` 表达。
- **独立输出**：看见点单情境，不看词表说出合适句子。
- **迁移使用**：从点咖啡换成点茶、结账、外带，表达仍自然正确。
- 初次课不追求所有词都进入最后一级；记录错误，反复练习。
